# Global Green Energy Report 2026

## Project Description
The **Global Green Energy Report 2026** is a simple HTML5 technical report project that presents information about renewable energy sources and their annual growth trends. The report focuses on sustainable energy solutions such as solar, wind, and geothermal energy.

## Features
Semantic HTML structure
Navigation menu with anchor links
Executive summary section
Annual growth report
Renewable energy resource descriptions
Comparison data table
Footer with contact information

## Technologies Used
HTML
